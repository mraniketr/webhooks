Pipeline: event is persisted, the pre-action runs (it sets a key-value pre object), then the payload plus pre is forwarded to each enabled subscription. Use {{ pre.key }} in subscription URL, headers & JSON. Deliveries are logged per event.
PRE-ACTION

Edit pre-action

One JS script per webhook. Set a key-value pre object — subscriptions use {{ pre.key }}.

Assign a plain object to pre — values can be plain text/numbers, {{ body.x }} templates, or references like event.payload.x. Only pre assignments run (no loops, functions or fetch). Leave empty for no pre-action.
